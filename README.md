# widgets

Desktop widgets for Wayland compositors: a status bar, a notification sidebar
and an application launcher. Rust + GTK4 + gtk4-layer-shell, colored by
[palette](https://github.com/Saravenpi/palette).

Works on sway, niri and Hyprland (anything speaking wlr-layer-shell).
Requires Wayland; exits with a clear error elsewhere
(`gtk4_layer_shell::is_supported()`).

## Crates

| Crate | Binary | What it does |
| --- | --- | --- |
| `statusbar` | `statusbar` | Top bar: workspaces (per-compositor IPC), clock |
| `sidebar` | `sidebar` | Notification daemon + overlay list, `mod+n` toggle |
| `launcher` | `launcher` | Centered dmenu-style app launcher, `mod+space` |
| `shell-common` | (library) | Palette CSS loading, layer-window boilerplate |

## Colors

Every widget loads `~/.config/widgets/palette.css` at startup (generated by
`palette sync`), which defines `@palette_bg`, `@palette_fg`, `@palette_cursor`
and `@palette_color0`..`@palette_color15` as GTK named colors. Widget
stylesheets reference those tokens; if the file is missing, built-in defaults
keep the widgets running.

## Build

```sh
make build     # cargo build --release
make install   # copy the three binaries to ~/.local/bin
```

System dependencies:

- Alpine: `apk add gtk4-layer-shell-dev`
- Debian/Ubuntu: `libgtk-4-dev` + gtk4-layer-shell dev package
- Arch: `gtk4` + `gtk4-layer-shell`

## Running

Start from your compositor, binaries live in `~/.local/bin`:

```text
sway      exec $HOME/.local/bin/statusbar
niri      spawn-at-startup "$HOME/.local/bin/statusbar"
hyprland  exec-once = statusbar
```

Keybinds: `mod+n` runs `sidebar toggle`, `mod+space` runs `launcher`.
